TARUMT Resort Management System

How to run in NetBeans:
1. Open NetBeans.
2. Choose File > Open Project.
3. Select this project folder: resort-management-system.
4. Run the project. The main class is main.

Important files:
- Source code is in the src folder.
- Data text files are in the project root folder.
- Main class: src/main.java

Required data files:
- guests.txt
- rooms.txt
- bookings.txt
- billing.txt
- housekeeping_task_history.txt
